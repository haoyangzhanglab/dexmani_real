删除与保留的机制

删除（任务书要求退出）

  • latest-wins lease：valid_until / TTL / minimum-delivery-window / latest-ticket authority / action_validity_s
  • 通用 timing gate：max_input_age_s / max_grid_lag_s / _input_is_fresh / command_feedback_is_fresh / stale escalation 计数
  • 观测层 age/skew/grid-lag 二次准入；点云构建前后 age drop
  • arm worker 对同一软阈值的重复 hard reject 与 reject_coupled_command_if_current
  • IK_FAIL>4 整段 episode 拒绝；policy heartbeat 线程（改为 is_alive/exitcode 监管）
  • 稠密 0.02 rad workspace critic → 必要端点检查

保留（有意不动）

  • 硬边界：joint limit、SDK 边界校验、e-stop、SafetyState.FAULT 路径
  • 因果与 identity：source ≤ commit ≤ query anchor、camera generation、RGB identity、tactile all-valid
  • 真实 source stall（producer 拥有）与 I/O worker heartbeat 存活；慢 predict 不被 loop heartbeat 否决
  • teleop/keyboard/calibration/replay 的 workspace segment gate —— 端点检查看不到的关节空间路径偏移，删除无证据支持
  • synchronous no-catch-up；hand slew / CRC / exact-endpoint ACK 游标
  • 显式用户 discard 的破坏性语义；单事务原子发布
