## Classification and evidence

The unit of classification is a check, not its containing function. A function
can enforce several categories. STRUCTURAL, PAYLOAD_NUMERICAL, INTERPRETATION,
and VARIABLE_PREPROCESSING checks remain. FIXED_SCHEMA_IDENTITY means an identity
already uniquely determined by processed schema v14 that affects neither tensor
values nor their interpretation nor variable preprocessing, and has no downstream
consumer. A literal comparison alone does not establish this category.

## Producer → transformation → consumer traces

- **Persisted training artifact:** [processing.py](../dexmani_real/dataset/processing.py)
  `_write_attrs` records the contract; `_write_processed_episode` writes aligned
  state/action/tactile arrays, derived FK fields and configured visual outputs.
  `process_episode_root` validates staging before publishing. `export.py`
  `_inspect_artifact` validates the complete persisted v14 artifact, then
  `_policy_zarr_v7_keys` selects the frozen v7 projection; `_copy_data` concatenates
  that projection and `_validate_zarr` checks the resulting staged store.
- **EEF and fingertips:** [arm_fk.py](../dexmani_real/planning/kinematics/arm_fk.py)
  `compute_eef_pose_history_xarm_base` and
  [fingertip.py](../dexmani_real/planning/kinematics/fingertip.py)
  `compute_fingertip_history_xarm_base` produce frame/order/derivation-dependent
  values. Processing and deployment reuse these mathematical owners. The
  [processed visualizer](../examples/visualize_episode_processed.py) also consumes
  EEF/fingertip values. Identical array dimensions cannot certify their meaning.
- **Tactile (historical):** `clean.py` (now deleted)
  `select_tactile_rows_to_references` selects causal raw rows; processing writes
  both contact and full tactile payloads with matching provenance. Deployment's
  [observation.py](../dexmani_real/deployment/inference/observation.py) tactile
  history readers enforce freshness/calibration/causality before
  `_to_policy_observation` projects requested arrays. SDK order and unknown-SI
  labels must not be silently reinterpreted as verified force or spatial geometry.
- **Point cloud:** [PointCloudConfig](../dexmani_real/config/pointcloud.py), the
  table configuration, [dataset derivation](../dexmani_real/dataset/pointcloud.py)
  and [sensor pipeline](../dexmani_real/sensor/pointcloud.py) determine numerical
  processing. Persisted identity and runtime-expected PolicySpec semantics keep
  sampling, transforms, colors and table configuration visible at admission.
- **Public model boundary:** [lifecycle.py](../dexmani_real/deployment/lifecycle.py)
  calls `validate_policy_runtime_compatibility` before starting hardware resources.
  Observation assembly produces the ordered NumPy mapping; the
  [DexManiPolicyAdapter](../dexmani_real/deployment/inference/dexmani_policy.py)
  checks that the loaded spec matches the inspected spec and passes those arrays
  to the public policy runtime. No policy implementation was modified or used as
  evidence that Real compatibility checks can be removed.

`PolicySpec.observation_fields[*].semantics` is part of Real's **public
compatibility contract**, alongside shapes/dtypes, modalities, action semantics
and timing. The current explicit semantic comparisons cover `eef_pose`,
`tactile_force`, `fingertip_points` and `point_cloud`; this audit does not claim
that Real performs the same semantic-map comparison for every other modality.

## Fixed-identity deletion decision

Every deletion would require all five proofs: v14 uniquely fixes the identity;
no tensor-value effect; no interpretation effect; no variable-preprocessing
effect; no downstream consumer.

| Apparent candidate | Evidence that prevents deletion |
| --- | --- |
| Schema name/version/domain constants | These select the external artifact contract. Structural/domain admission cannot be inferred from an untrusted version attribute alone. |
| EEF frame/components/derivation/algorithm ID | These specify mathematical interpretation and FK identity. v7 omits EEF values and their attributes, but `_inspect_artifact` deliberately admits the complete v14 artifact first; omission from the projection is not proof of no consumer. |
| Full-tactile representation/order/unit/verification constants | These prevent reinterpreting SDK arrays as a different order, verified SI force or known taxel geometry. Export admission and Real's public model compatibility remain consumers even though frozen v7 omits the full tactile tensor. |
| Fingertip derivation/policy identity | These describe derived geometric values and are retained in exported semantic attributes, compared across episodes and against runtime model expectations. |
| Point-cloud policy/color/sampling/transform/table identity | These constrain numerical processing and interpretation; table parameters and other resolved preprocessing are variable. Exported attributes and deployment compatibility consume them. |

No inspected check qualifies for deletion as FIXED_SCHEMA_IDENTITY. No new
validation, schema/version change, export policy change or normalization was
introduced to obtain this result.
