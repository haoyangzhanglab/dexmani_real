# 实验数据

## Raw Episode

VR 遥操作和策略运行共用录制链路。Raw Episode 保存实测关节、触觉、原始 RGB-D、动作目标和各观测的来源时间，可附加按行对齐的手物交互（HOI）标注。[物体重建与 HOI](object_reconstruction.md#跟踪与逐行快照)

## 时间与动作

相机、机械臂和灵巧手独立采样。控制循环按观测行组合快照，各模态保留自己的来源时间。暂停或采样中断会划分连续段。

动作记录保存主机已确认提交的臂手绝对关节目标，实测关节反馈反映机器人实际运动。VR 录制成功提交的行。策略正常等待时可记录没有新目标的观测行。真机回放直接使用所选连续段的原始目标，要求该段每行都有完整目标。

## 图像与模型输入

场景点云从原始 RGB-D 生成。策略中的 RGB 与 Zarr 中的 RGB、深度统一使用针孔图像几何。

## 按需导出

训练数据按所需模态导出为 Canonical Zarr，所选模态须通过有效性检查。每个连续段成为独立训练轨迹，并保留与原始录制及行范围的对应关系。手部几何由实测关节经正运动学得到，并与同一观测行的 HOI 物体点云配对。

导出动作时，等待行沿用本段上一次已提交的目标。首次提交前使用本段首行的实测关节状态。关节动作与末端动作来自同一目标序列，后者通过正运动学转换机械臂目标并保留手关节目标。
