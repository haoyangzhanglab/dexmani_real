# XHand 手部重定向

使用 Pinocchio FK、解析雅可比和一次有界 NLopt SLSQP 求解，联合拟合近端/末段方向、骨链位置和有意对指距离。目标是按 XHand 的实际自由度匹配整手姿态。

## 模块与调用链

| 模块 | 职责 |
| --- | --- |
| `teleop/retargeting/landmarks.py` | 掌系、骨长检查、固定骨长标定及 XHand 目标对应 |
| `teleop/retargeting/objective.py` | 位置、方向、对指、阻尼的函数值与解析梯度 |
| `teleop/retargeting/solver.py` | 求解限位、滤波、拒绝原因及提交状态 |

在线入口为 `sensor/vr.py` → `teleop/vr.py::VRController` → `HandRetargeter`。腕部映射与手部拒绝统一通过 `ActionResult` 返回，拒绝原因随本次结果传递。候选求解不推进状态；只有设备提交正常返回后，控制线程才从实际 `RobotCommand` 更新 warm start、阻尼中心、滤波中心和时间戳。每个控制 tick 都重新映射最新有效 landmarks，重复 VR 帧也可在速度限制内继续收敛。每段在停止期间完成录制初值等待及 writer 初始化，writer ready 后等待新的关节反馈，再 prepare streaming 并复核反馈和控制输入。进入 ACTIVE 时建立首次等待期限及录制时长预算；起点检查与参考初始化统一在首次提交前的控制步，会话内骨长标定保留。普通几何退化或已知求解失败在上一有效目标的原期限内重发完整 arm+hand 命令；不续期、不混入失败候选。首目标等待直接以尚无有效提交命令表示；等待期间不发送或录制虚构动作，每次尝试用最新实测关节和 VR 重建未生效参考，等待期限不变。首次提交正常返回后固定本段锚点并播放开始提示。到期、来源过期、取消和真实故障仍结束当前段。

运行入口在构造前检查机器人配置和控制频率。关节反馈的形状及有限性由 XHand SDK 边界保证；HTS 21 点在接收并转换为 FLU 后完成同样检查。reset 仅将 `1e-6 rad` 内的实测边界舍入误差归一，并复制为首次参考，不把求解候选当作实测或已提交命令；求解 seed、候选和提交参考也不共享可变数组。保留 float64 转换、骨长和掌退化检查。

除上述数值舍入量外，实测起点必须位于 `hand.qpos_min_rad/qpos_max_rad` 内；超出时在发送任何本段目标前列出关节、实测值及要求范围，只拒绝本段，健康会话可就位后再次 B。默认 distal 操作下限为拇指 10°、其余手指 5°。默认显式 HOME 目标的 ±5° 到位区间处于操作范围内。自定义范围或 HOME 后，须相应留出到位余量；HOME 报到位并不豁免开始时的实际范围检查。不自动入域、HOME 或清零。

腕部原始四元数在 SDK 基变换前检查并归一化，零范数或非有限姿态被拒绝。接收边界的坏帧不发布，控制侧继续按原来源时间检查观测时效。

每段首次结束时记录一条简短原因日志；求解拒绝包含具体原因，异常保留原 traceback。普通 teleop 不因计算跨过名义 tick 而丢弃有效目标，不补发积压 tick；调度沿首 tick 的固定时钟网格推进，迟到跳到未来网格点，每段重新初始化。网格恢复可能缩短相邻实际执行间隔；提交前检查停止和来源年龄。正常控制步不逐帧保存诊断，重复 VR 帧仍运行当次求解。Raw 保存观测、控制及各来源时间；动作截止时间和正常返回时刻 `submit_end_ns` 用于运行期控制，不另行归档。

等待 arm 邮箱锁时耗尽命令期限，同样抛出 `OperationCancelled`，保留原邮箱目标并结束当前段。正常保存/丢弃提示以最终收尾请求的结束原因为准；取消或故障不播放正常完成提示，异常详情只用于诊断。

VR 建立锚点时，实测 FK 必须属于名义工作空间（只允许 `1e-9 m` 计算舍入）；否则拒绝本段，不通过裁剪自动移动到边界。jog 获取新参考时使用 `workspace_with_tolerance` 的端点验收范围；内缩 margin 只限制新目标，每轴裁剪范围包含当前参考点。因此 `z=0.496 m` 可在松键清除参考后再次向内退回，向外输入不扩大越界，纯旋转及未输入平移的轴保持原位置。超出端点验收范围仍拒绝并减速保持。B 重开段重新获取实测锚点，策略 EEF 投影行为不变。

机械臂 IK 使用原生 Pinocchio，每个求解器复用自身的 `ArmFK` model/data，不与碰撞或手部模型共享可变 data。使用单初值有界 TRF 和解析雅可比，最终检查实际候选的关节范围、碰撞及 workspace；可执行不表示达到输入位姿。公式、参考生命周期与离线对照见[共享 EE IK](#共享-ee-ik-连续性与离线验证)。

## 输入与机构对应

右手输入为米制、HTS 原始 21 点：wrist=0；拇指 CMC/MCP/IP/TIP=1/2/3/4；四指 MCP/PIP/DIP/TIP=5–8、9–12、13–16、17–20。接收端将 Unity 左手 XYZ 转为 FLU `(z,-x,y)`。掌系由 wrist→middle MCP 与 pinky MCP→index MCP 确定：+X 掌侧、+Y 拇指侧、+Z 中指侧，不逐指配准。

启动采集 25 个新鲜且来源时间递增的有效样本，固定 15 段骨长和掌宽的中位数；不要求平手，不从弯曲前缀估计零关节角。有效骨长范围 2–180 mm，`calibration_max_relative_mad` 控制标定样本的统计稳定性，默认要求相对 MAD≤10%。`bone_length_tolerance` 控制运行帧相对标定骨长的偏差，默认须≤35%，异常帧不产生新候选；若控制层正常重发旧命令，仅推进旧命令的提交时间。两个门限分别要求有限且位于 `(0, 1)`，不要求大小排序。会话内复用标定；Raw 保存实际使用的 `vr_to_robot_rotation`，不归档骨长标定。

标定期间，每个采样帧先完成掌系与骨长校验，无效时继续采样；通过后只保留已算出的 16 项测量，最终直接求 median/MAD，不再次准备原始帧。URDF 的中立目标 Frame、固定段长、关节轴、轴心和基部限位在重定向对象构造时固定，逐帧映射复用这些几何量。

| 手指 | 人体方向 | 机器人骨段 | 限制 |
| --- | --- | --- | --- |
| 拇指 | MCP→IP、IP→TIP | thumb_rota_link1→link2→tip | 三轴不能表达完整人体拇指自由度 |
| 食指 | MCP→PIP、DIP→TIP | index_rota_link1→link2→tip | 约 ±10° 侧摆，没有独立 DIP |
| 中/无名/小指 | MCP→PIP、DIP→TIP | 对应 link1→link2→tip | 两轴屈曲，没有侧摆和独立 DIP |

位置目标由局部屈曲平面中的单位方向乘以 URDF 固定段长构造。Thumb 根据 CMC→MCP 估计基部对掌角，Index 根据 MCP→PIP 估计有限侧摆角；都使用实际基部轴上的有向夹角并按 URDF 限位截断，然后旋转第一目标 Frame 和屈曲平面法向。Middle/Ring/Pinky 使用固定 URDF 基座。Thumb 的两段方向分别来自 MCP→IP、IP→TIP；非拇指远段由两段标定骨长加权当前单位方向，再投影、归一化，不使用弯曲弦长缩放机器人 link。方向目标独立保留投影后的 DIP→TIP。基部方位或方向投影退化时拒绝整帧，不使用中立方向占位。

重定向、数据导出和策略观测共用组合 URDF 的手部子树。SDK/URDF 顺序按关节名对应，雅可比在堆叠后统一转换为 SDK 列顺序；运行限位由 `hand.qpos_min_rad/qpos_max_rad` 指定，并检查其包含于 URDF 限位。人体当前骨段长度用于容差检查和单位方向计算，标定骨长用于远端合成。

## 目标、参数与运行约束

位置残差按固定 0.10 m 归一化，使用 0.02 m 阈值的径向 Huber；归一化尺度不作为配置项，以免与骨链、指尖及捏合权重重复调节目标强度。方向使用 `Huber(u_robot-u_target, 0.3)/0.3`，其中 `u_target` 为投影后的单位方向，阈值约对应 17.3°。方向梯度包含完整归一化导数 `(I-uuᵀ)J/length`。阻尼系数为 `damping_s/dt`。

| 参数 | 当前值 |
| --- | ---: |
| shape / tip 权重 | 0.25 / 2.0 |
| proximal_direction / direction 权重 | 2.0 / 1.0 |
| direction_huber_delta | 0.3 |
| pinch 权重 | 8.0 |
| pinch 开始 / 完全激活距离 | 30 / 15 mm |
| damping_s / smoothing_tau_s | 0.002 / 0.02 s |
| 最终命令变化率上限 | 4 rad/s |
| 求解预算 | 50 次 / 25 ms |

次数预算限制求解工作量，时间预算限制计算耗时。算法内部数值常量 `LOSS_TOLERANCE=1e-7` 只用于 NLopt 绝对目标收敛容差。读取优化器返回的最优值检查有限性。MAXEVAL/MAXTIME 返回的有效有界候选可接受；只有显式的 `HandGeometryRejected` 和 `RoundoffLimited` 是普通拒绝；一般 ValueError/RuntimeError、非成功返回状态、坏维度、非有限或越界优化结果均保留异常，终止当前段。阻尼在优化中惩罚相对已提交命令的位移，EMA 在求解后平滑输出，两者作用不同。

捏合是辅助目标：四组目标距离直接取映射后的机器人指尖目标距离，30→15 mm 的 smoothstep 激活，无末段角度门控，不压缩间隙。掌宽用于标定及运行时几何稳定性检查。它是几何对指代理，不代表实际接触。

求解变量是滤波前候选。最终命令为 `reference + alpha*(candidate-reference)`，`alpha=-expm1(-dt/tau)`；`tau=0` 时 `alpha=1`。`dt` 来自本次控制计算开始与上次 `send_action` 正常返回时刻 `submit_end_ns` 的 monotonic 时间差，不使用 VR 来源帧间隔。首次参考来自范围内的真实姿态及其观测时刻；时间相等直接返回该参考，不获得名义周期的运动额度，时间倒退明确报错。例如间隔 10 ms、上限 4 rad/s 时，最终 `RobotCommand` 每轴相对真实起点最多变化 0.04 rad。失败候选、取消或提交抛错（包括部分设备已提交）不推进参考。普通保持真实重发旧命令且正常返回时，关节和 EEF 值不变，手部参考时间更新为本次返回时刻，避免恢复时累积运动额度。搜索步长除以 alpha，保证滤波不额外压低最终变化率上限。返回前仅裁剪浮点舍入误差；后续 mapper 使用相同操作范围，不会再引入预弯跳变。发送时仍检查机械范围和反馈时效，hand SDK 发送前还须复核同一命令期限；arm 已发布而 hand 发送前到期会取消并停止，录制保留本次提交尝试，但不推进参考。SDK 调用开始后跨期限不追溯否定发送；`commit` 消费提交尝试正常返回的不可变命令。

该约束限制提交尝试目标序列的变化速率。单控制线程中，上次返回时刻不晚于本次计算起点，因此按这个差值分配额度相对于两次实际提交间隔更保守。偶发写 CRC 仍完成本次提交尝试并推进参考，下一周期发送最新绝对目标；连续 5 次写 CRC 或真实 SDK 故障抛错，结束本段且不推进该次参考。提交尝试正常返回不表示物理到位、设备执行 ACK 或实测电机速度满足同一上限。

## 验证边界与限制

XHand 无法独立表达人体 DIP 屈曲及中/无名/小指侧摆，拇指也只有三个驱动轴。方向与位置目标可能无法同时满足；指尖接近不能证明整手姿态一致。强屈曲和部分拇指对掌姿态仍需进一步验证，离线求解结果不代表机器人已经执行或达到目标，当前实现尚未经真机验收。

实现参考 [Sharpa](https://github.com/sharpa-robotics/sharpa-vision-retargeting-sdk/blob/73ac80e980b980b11d8853b874f8efea79095add/supplements/teleop_hand.py) 的固定形态思想及 [Wuji](https://github.com/wuji-technology/wuji-retargeting/blob/531f6ed4250b475d2e9231f54e988fc9b1c5b4ea/wuji_retargeting/opt/adaptive_analytical.py) 的形态/方向联合拟合，没有照搬高自由度手对应或增加通用优化框架。


## 机构几何与数学目标

数据流：HTS 右手米制 21 点 → 既有 Palm Frame → 15 骨段与掌宽检查 → URDF 基部转角及局部平面投影 → 定长位置/方向/四组距离目标 → 单一有界 SLSQP → dt-aware EMA → 正常发送后 commit。运行配置、权重、限位、求解预算和控制接口均未修改。

HandFK 从组合 URDF 手部子树提取中立关节轴心和 LOCAL_WORLD_ALIGNED Jacobian 的角速度列，按 joint name 转为 SDK 顺序。屈曲关节及可动基部沿目标 Frame 的父关节链提取，HandGeometry 保存一次提取的几何。当前模型两屈曲轴逐指平行：Thumb 法向约 `(0.965126,-0.039302,-0.258820)`；其余为 `(0,1,0)`。Thumb 基部轴为 `(0,0,-1)`、范围 `[0,1.832]` rad；Index 基部轴为 `(-1,0,0)`、范围 `[-0.174,0.174]` rad。Thumb 中立两段为 55.3/50.22764994 mm，Index/Ring/Pinky 为 55.8/42.24829241 mm，Middle 为 55.8/42.248 mm。以上仅为提取结果，代码不硬编码这些数值。

设 `normalize` 为单位化，基部轴为 a，轴心为 c，人体与中立参考方向在垂直于 a 的平面投影后分别为 v、v₀：

\[
\theta=\operatorname{clip}(\operatorname{atan2}(a^T(v_0\times v),v_0^Tv),\theta_{min},\theta_{max}),\quad
b^*=c+R_a(\theta)(b_0-c),\quad n^*=R_a(\theta)n_0.
\]

Thumb 的中立方位来自轴心→第一 Frame；Index 来自第一机器人段。固定基座三指直接使用中立 b、n。令 \(P=I-nn^T\)，所有机器人位移均为 \(L^{URDF}\operatorname{normalize}(Pv)\)。非拇指远段使用 \(v=l_1^{cal}u_{PIP-DIP}+l_2^{cal}u_{DIP-TIP}\)；末端方向损失仍使用 \(\operatorname{normalize}(Pu_{DIP-TIP})\)。投影退化阈值为无量纲 1e-6；合成向量先除以标定总长统一阈值量纲。

记径向 Huber 为 ρ，s=0.10 m，δp=0.02/s，δd=0.3，机器人段单位方向为 u，已提交参考为 qᶜ：

\[
L_p=\frac15\sum_{f,j}w_{fj}\rho_{\delta_p}((p_{fj}(q)-p^*_{fj})/s),\quad
L_d=\frac1{5\delta_d}\sum_{f,k}w_k\rho_{\delta_d}(u_{fk}(q)-u^*_{fk}),
\]
\[
d_i^*=\|p^*_{0,2}-p^*_{i,2}\|,\quad
x_i=\operatorname{clip}((0.03-d_i^*)/0.015,0,1),\quad a_i=x_i^2(3-2x_i),
\]
\[
L_{pinch}=\frac84\sum_{i=1}^4a_i^2\rho_{\delta_p}((\sqrt{\|p_{0,2}-p_{i,2}\|^2+10^{-12}}-d_i^*)/s),\quad
L_t=\frac{0.002}{2dt}\|q-q^c\|^2,\quad L=L_p+L_d+L_{pinch}+L_t.
\]

位置权重：所有第二 Frame 为 0.25、TIP 为 2；第一 Frame 仅 Thumb/Index 为 0.25，其余为零。方向近端/末端权重为 2/1。保留完整解析归一化导数、批量 Jacobian 和零 Pinch 权重跳过。没有新配置、耦合或自适应权重。

**可达性边界：** 定长与平面一致不保证整链满足关节限位。本地 1,880 帧按指定映射构造的 Thumb 远端角均低于当前 10° 操作下限；173701 首帧要求约 −13.22°，无界 FK 重建误差约 2e-17 m。依照确认的任务范围不额外裁剪屈曲目标；保留有界优化折中。不能将此实现称为所有位置和方向同时精确可达。

## 共享 EE IK 连续性与离线验证

2026-11-06：替换无界 CLIK、多候选排序、快速接纳和零空间试探。遥操作、策略 EEF、jog 使用同一个单初值 SciPy TRF 最小二乘求解，最多 30 次函数评估；不做求解后等价角换支或裁剪。joint mapper 的等价角投影保留。配置仅暴露目标变化速度和最大超前量，构造求解器时先检查参数有限且为正，再应用设备速度上限。

残差为 `We log(T(q)^-1 Tg)` 与合并的七维关节正则：平移除以 0.3 m，旋转除以 1 rad；D 为 `[4,1.8,1.2,0.6,0.6,0.9,0.35]` 的平方根对角阵。λc=λa=0.03，以实际带圈数的关节坐标计算差值。任务雅可比为 `-We Jlog6(E^-1) J_LOCAL`，使用真实 custom_eef_link 偏置。有限差分核对误差小于 1e-7。

运行对象拥有 qc、qa 和提交时刻；IK 仅拥有模型和计算缓存。qa 来自首次成功提交的尝试所用实测值，本段内固定。尚无提交参考时，qc、qa 都取校验后的实测 qm，h 直接取名义控制周期，与反馈年龄无关；已有参考时，h=min((control_ns-submitted_ns)*1e-9, period_s)。负时间差报错，零时间差允许 h=0 且仍检查参考和候选几何。清除参考后重新使用首帧规则；设备反馈的未来时间、过期、数值和关节限位检查仍由原边界负责。上下界为操作限位、qc±v*h、qm±lead 的交集。默认速度 75°/s（受设备速度上限限制），超前 10°。参考失配及有限但超出操作限位的实测必须终段，设备会话按入口既有规则收尾；非有限值和格式错误继续显式传播。触及边界本身允许继续跟随。

候选必须有限、在固定边界内、通过最终碰撞与 workspace 验收，目标函数不明显劣于初值；workspace 检查直接使用求解器已计算的候选 FK，碰撞模型仅负责碰撞检查。预算耗尽不单凭 success 拒绝。TRF 会将边界初值内移约 1e-10，因此目标函数比较使用 1e-9*max(1,F_initial) 数值容差，不放宽关节输出范围。局部可执行与末端到达是不同概念。提交完成也不表示设备消费或到位。

普通遥操作拒绝仍在旧期限内成对重发旧命令，记录旧命令，更新提交时间而不更新新 EE 意图或 qa；这不是制动。手部提前拒绝同样检查 arm 参考。jog 的普通拒绝/松键保留 arm_hold，正常返回后清除参考，下次从实测建立；参考失效走取消收尾。已有提交参考时，增量从已提交解的 FK 出发。jog 调度沿固定时钟网格推进，每次到期最多执行一步，错过周期不补发；启动和 HOME 完成后按当前时间重新建立起点。
